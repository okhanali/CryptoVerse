🪙 CryptoVerse

CryptoVerse, kripto para dünyasına yönelik modern bir web arayüzü sunmak amacıyla geliştirilmiş bir projedir. Bu projede HTML, CSS ve Bootstrap kullanılarak responsive (mobil uyumlu) ve kullanıcı dostu bir tasarım oluşturulmuştur.

Kullanıcılar, sade ve şık arayüz sayesinde kripto para bilgilerine kolayca ulaşabilir. Tasarım sürecinde Bootstrap’in grid sistemi ve hazır bileşenleri aktif şekilde kullanılarak hızlı ve düzenli bir geliştirme süreci sağlanmıştır.
